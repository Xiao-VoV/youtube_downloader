# Mac UI 重构交接

## 分支与范围

工作分支为 `refactor/mac-ui`，从干净的 `main` 创建。改动保留在该分支工作区，未提交、未合并、未推送。下载引擎、依赖清单和锁文件未修改。

本次依据确认后的精简原型调整原生 GPUI 界面：统一浅色/深色色板、雾灰侧栏、蓝色选中态与主操作；移除常驻说明底栏，操作通知可手动关闭；重新组织新建下载、草稿、预览、队列、历史表格及工具设置。下载配置使用侧边配置列表、分组表单，网络授权及高级参数默认折叠；字段解释放在帮助提示中。保留真实下载、草稿恢复、配置保存/删除、历史排序/多选/分页/显示列/危险删除确认，以及工具版本管理调用。

队列进度使用下载事件中的真实已下载字节与总量，仅表示当前轨道。启动、合并、转换和总量未知时不显示确定百分比；新增的进度状态按任务与 attempt 隔离。英文词条同步补充。窗口默认尺寸调整为 1120 × 780。

## 与 HTML 原型的区别

软件仍使用原生 GPUI 页面路由，预览不是网页式模态弹窗。媒体区域当前使用中性视频/音频占位，不将原型插画或虚构封面带入真实软件；真实缩略图加载与缓存未在此次重构中新增。原型中的搜索和状态筛选未接入原先没有对应状态的原生页面。本次不添加暂停、播放列表或新的下载调度能力。

`git diff --check` 通过。15 个修改的 Rust 文件经 WebAssembly rustfmt 格式处理，并用 Rust tree-sitter 与 HEAD 对照，未出现新增语法错误。独立静态审查检查了相关 GPUI 调用、取消及进度隔离、持久化和业务动作保留；发现的新文案英文缺失已补充。进度隔离现有测试中补充了比例计算、未知总量、越界限制、旧 attempt 和后处理重置断言，但未运行。

## 第二轮：应用专属组件

新增 `view/controls.rs`，集中定义按钮的普通、悬浮、按下、禁用及分段选中视觉，使用组件的 custom variant，而非仅在默认按钮上覆盖背景。保留原生 Button 的键盘、焦点和 tooltip，保留 InputState 与输入焦点环，统一单行高度与圆角。历史、下载、配置和设置页动作接入同一控件层。

新增 `view/preferences.rs`，设置页拆为通用与下载工具。通用页用 GPUI 基础图形绘制系统/浅色/深色预览卡；工具页默认展示工具及单行路径摘要，点击编辑才显示输入，只有编辑模式展示探测、验证和保存。路径摘要缩写 HOME，完整路径通过 tooltip 查看，且不将路径已定位声称为健康检查通过。托管版本以版本号及使用中标记呈现，保留运行中版本保护。

独立审查发现隐藏路径输入与保存操作的显示错位，已将编辑操作限定到编辑模式，并使自动探测保持编辑展开。通知取消了基于相同字符串的超时机制，避免重复错误静默消失，可手动关闭。当前17个新建/修改 Rust 文件通过语法检查及 WASM rustfmt，工具操作/版本保护和翻译无重复检查通过；未完成编译和 Mac 原生截图验收。

## 第三轮：下载工作区

新增 `view/media.rs`，统一标题、频道、时长和格式标签。列表标题限制单行并提供完整 tooltip；视频画质显示为上限而不是实际已取得的分辨率。时长处理未知值、非有限值和长视频，并添加单元测试（当前未执行）。草稿提供显式“查看并下载”，预览媒体信息独立分组；复制命令移入命令折叠区，下载操作保持在底部。

队列采用一个连续面板，运行、等待和恢复项共用相同的内容层次。列表元素使用任务稳定 ID，而非会随删除改变的索引。取消排队项先持久化移除，成功后才从内存队列删除；失败保留任务并显示错误。恢复项新增取消入口。未改变引擎、依赖和调度能力。

本轮18个新建/修改 Rust 文件通过语法检查，WASM rustfmt 和差异检查通过；独立审查检查了类型、闭包所有权及下载确认保护，发现的队列取消持久化与恢复项取消入口问题已修正。没有本地 Rust 工具链，新增测试和 Mac 原生布局尚未运行，不以静态检查替代编译验收。

## 第四轮：历史工作区

历史页维持连续表格，批量操作只在有选择时出现；使用真实 Checkbox 替换字符选择框，排序表头改用原生 Button，页大小使用统一分段控件。记录选择框和内容单元格以记录 ID 标识，排序或翻页后不会按行号复用其控件身份。状态同时呈现图标和文字，并适配深色主题；无产物记录的大小显示为“—”，新增对应单元测试但尚未执行。

列设置按基本信息、媒体信息、文件与来源三组组织，覆盖全部15个字段；必选列限制、配置保存和规范化逻辑不变。批量打开10项限制、运行中删除保护和原有删除对话框（可选移到废纸篓）保持原样。删除完成时原有处理器会重置到第一页；本轮未修改数据库或删除处理层。

本轮修改文件经 WASM rustfmt 和 Rust 语法检查，`git diff --check` 通过；独立只读审查未发现确定的编译错误，选择/分页/列及危险操作调用的静态检查通过。这不等于编译、测试或键盘可访问性验收通过；仍需本机运行 `cargo check` 以及原生窗口检查。
